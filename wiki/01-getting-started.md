# Getting Started

The **Spyro 1 Practice ROM** is a mod for *Spyro the Dragon (NTSC)* that adds a suite of practice and speedrun tools, including full save states, a level select, IL timing, ghost replays, visualizers, and much more.

---

## Platform Compatibility

This mod supports multiple platforms. **Download the correct version for your hardware** — the PS2 (Deckard) build will not work on PS1 or emulator, and vice versa.

| Platform | Save States | Ghost Replay | Notes |
|---|---|---|---|
|[PS2 75k–90k](https://github.com/C0mposer/Spyro-1-Practice-Rom/releases/download/fullrelease4.1/Spyro.1.Practice.Rom.PS2.Deckard.zip) | Full | Yes | Recommended console for full feature set |
| Emulator (Duckstation) | Full | Yes | Recommended emulator for full feature set |
| |
| [PS2 30k–70k](https://github.com/C0mposer/Spyro-1-Practice-Rom/releases/download/fullrelease4.1/Spyro.1.Practice.Rom.PS2.IOP.zip) | Partial | No | Spyro/camera position only |
| [PS1](https://github.com/C0mposer/Spyro-1-Practice-Rom/releases/download/fullrelease4.1/Spyro.1.Practice.Rom.PS1.zip) | Partial | No | Spyro/camera position only |
| [Emulator (Any other PS1 emulator)](https://github.com/C0mposer/Spyro-1-Practice-Rom/releases/download/fullrelease4.1/Spyro.1.Practice.Rom.PS1.zip) | Partial | No | Spyro/camera position only |

See [Platform Comparison](13-platform-comparison.md) for a complete feature matrix.

## Downloads

### PS2 (75k–90k) — Deckard
Full save states and ghost replay. Recommended setup.

[Download PS2 Deckard (bin & cue)](https://github.com/C0mposer/Spyro-1-Practice-Rom/releases/download/fullrelease4.1/Spyro.1.Practice.Rom.PS2.Deckard.zip)

To play on PS2 you need either a [MechaPwn'd](https://github.com/MechaResearch/MechaPwn) or modchipped PS2. The disc must be burned to a **CD, not a DVD**.

### PS2 (30k–70k) — IOP
Partial save states (Spyro/camera position). No ghost replay.

[Download PS2 IOP (bin & cue)](https://github.com/C0mposer/Spyro-1-Practice-Rom/releases/download/fullrelease4.1/Spyro.1.Practice.Rom.PS2.IOP.zip)

Same disc requirements as above.

### PS1 / Emulator
Works on original PS1 hardware and most emulators (PCSX-Redux, DuckStation, etc.).

[Download PS1/EMU (bin & cue)](https://github.com/C0mposer/Spyro-1-Practice-Rom/releases/download/fullrelease4.1/Spyro.1.Practice.Rom.PS1.zip)

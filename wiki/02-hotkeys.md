# Hotkeys

All default button combos for the Practice ROM. Many of these can be customized in the menu — see [Save States](04-save-states.md) for button remapping options.

---

## Global Hotkeys

| Action | Input |
|---|---|
| Open Custom Menu | L2 + R2 + Triangle |
| Open Level Select | Select |
| Quick Fly-In to Current Level | L1 + R1 + Triangle |
| Save State | L3 |
| Load State | R3 |
| Switch Savestate Slot (Left / Right) | Right Stick Left / Right |
| Moonjump *(IL mode must be OFF)* | L1 + R1 + L2 + R2 + X |
| Respawn Spyro (resets collectables) | L1 + R1 + Circle |
| Give Key | Triangle × 3 |

---

## Level Select (when menu is open)

| Action | Input |
|---|---|
| Fly in to Homeworld | L3 |
| Fly in — various directions | L1, L2, R1, R2, R3 |
| Digital pad alternative — fly in | Up (Homeworld), Down (R3 direction) |
| Cancel to RETURNING HOME instantly | Triangle (during fly-in) |
| Reverse fly-in angle | Circle (during fly-in) |

**Gem count adjustment during homeworld fly-in:**

| Action | Input |
|---|---|
| −1 gem | L1 |
| +1 gem | R1 |
| −10 gems | L2 |
| +10 gems | R2 |
| ±50 gems per frame | Hold L2 / R2 |

---

## Consistency Tracker

*(Only active when Track Consistency is enabled in Misc Settings)*

| Action | Input |
|---|---|
| Increment total attempts | Load State button |
| Increment successful attempts | Right Stick Up |
| Decrement successful attempts | Right Stick Down |
| Increment total attempts manually | L2 + R2 + Right Stick Up |
| Decrement total attempts manually | L2 + R2 + Right Stick Down |
| Show tracker for 2 seconds | L2 + R2 |
| Reset both counters | Load State × 3 |
| Reset both counters *(PS1 / 70k alt)* | Hold L2 + R2, then Circle × 3 |

## Controller Port Swap

| Action | Input |
|---|---|
| Switch active port to port 2 | Press any button × 3 on port 2 |
| Switch active port back to port 1 | Press any button × 3 on port 1 |

## Title Screen

| Action | Input |
|---|---|

---

## Notes

- **Moonjump** only works when IL Mode is OFF.
- **Right Stick** hotkeys are unavailable during consistency tracking when a different Switch Slot option is selected. Configure via Savestate Settings if there is a conflict.
- PS1 and PS2 30k–70k builds have slightly different available button options for Save/Load State — see [Save States](04-save-states.md).

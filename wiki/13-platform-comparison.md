## Platform Notes

### PS2 75k–90k (Deckard)
The recommended platform for the full feature set. Full save states capture the entire level state. Ghost replay is available with up to ~3:22 of recording time. Theatre mode, memory watch, collision wireframe, and the custom skin editor are all available.

### PS2 30k–70k (IOP)
Partial save states only — Spyro and camera position are saved but collectables and level state are not. No ghost replay, theatre mode, memory watch, or collision wireframe. Includes a **Respawn on Loadstate** toggle not available on other platforms. The consistency reset shortcut uses a different input: **Hold L2 + R2, then Circle × 3**.

### PS1
Same feature set as PS2 30k–70k. Partial save states, no ghost replay or advanced visualizers. The consistency reset shortcut uses the same alternate input as IOP.

### Emulator (PCSX-Redux / DuckStation)
Feature set is close to Deckard. Ghost replay is supported with a **significantly larger buffer** (~8:17 vs ~3:22). Theatre mode, memory watch, collision wireframe, and the custom skin editor are all available. Recommended for long-level ghost recording.

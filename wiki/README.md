## Quick Reference

**Open Custom Menu:** L2 + R2 + Triangle  
**Open Level Select:** Select  
**Save State:** L3 &nbsp;|&nbsp; **Load State:** R3  
**Switch Slot:** Right Stick Left / Right  
**Respawn:** L1 + R1 + Circle  
**Moonjump:** L1 + R1 + L2 + R2 + X  

For the full hotkey list see [Hotkeys](02-hotkeys.md).
